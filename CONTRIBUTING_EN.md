# Contributing to the Critical AI Literacy Skill

Thank you for your interest in contributing to this project!

## How You Can Contribute

### Reporting Issues

If you find a bug or have a suggestion:

1. Check whether the issue already exists in the [Issues](https://github.com/malkreide/critical-ai-literacy-skill/issues) section
2. If not, create a new issue with a clear title and description
3. Include examples of the problematic behavior if applicable
4. Tag the issue with appropriate labels (Bug, Enhancement, Question, etc.)

### Submitting Changes

1. **Fork the repository** to your own GitHub account
2. **Create a new branch** for your feature or bugfix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes** with clear, descriptive commit messages
4. **Test your changes** thoroughly
5. **Submit a Pull Request** with:
   - A clear description of what you changed and why
   - Reference to related issues
   - Examples of the improvement, if applicable

### Areas for Contributions

We are particularly interested in contributions in these areas:

- **Additional analysis examples** from public administration or education contexts
- **Translations** (French, Italian — to cover Swiss multilingualism)
- **Case studies** of AI systems in Swiss municipalities or educational institutions
- **Bias taxonomy extensions** for specific domains (e.g., healthcare, social services)
- **Integration guides** for different platforms and workflows
- **Feedback from practitioners** (teachers, administrators, AI specialist groups)
- **Documentation improvements**

### Guidelines

- Follow the existing code style and documentation format
- Keep changes focused and atomic
- Write clear commit messages
- Update documentation to reflect your changes
- Use Swiss German spelling conventions for German content (no ß, use ss instead)
- English content should use standard international English
- Be respectful and constructive in discussions

### Language

This project maintains parallel German (original) and English versions:

- **German files:** `SKILL.md`, `README_DE.md` — Swiss High German spelling
- **English files:** `SKILL_EN.md`, `README.md` — Standard English

If you modify the SKILL content, please indicate which language version you updated so the other can be kept in sync.

### Questions?

If you have questions about contributing, don't hesitate to:
- Open a [Discussion](https://github.com/malkreide/critical-ai-literacy-skill/discussions)
- Reach out via Issues
- Check the existing documentation first

## Code of Conduct

We are committed to creating a welcoming and inclusive environment. Please:

- Be respectful and considerate
- Welcome newcomers and help them get started
- Focus on what is best for the community
- Show empathy toward other contributors
