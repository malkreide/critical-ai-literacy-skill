# Contributing to Critical AI Literacy Skill

Vielen Dank für dein Interesse, zu diesem Projekt beizutragen! 🎉

## Wie du beitragen kannst

### 1. Issues melden

- **Bug Reports:** Wenn eine Analyse inkonsistente oder fehlerhafte Ergebnisse liefert
- **Feature Requests:** Neue Analysedimensionen, zusätzliche theoretische Perspektiven
- **Verbesserungsvorschläge:** Klarere Formulierungen, bessere Beispiele

### 2. Beispielanalysen beitragen

Besonders wertvoll sind:
- Analysen konkreter KI-Systeme im öffentlichen Sektor
- Fallstudien aus Schweizer Gemeinden und Kantonen
- Vergleichende Analysen (z.B. verschiedene LLM-Anbieter)

### 3. Übersetzungen

Der Skill ist auf Deutsch (Schweizer Rechtschreibung) verfasst. Übersetzungen in folgende Sprachen sind willkommen:
- Französisch
- Italienisch
- Englisch

### 4. Theoretische Erweiterungen

Vorschläge für zusätzliche theoretische Perspektiven oder Aktualisierungen bestehender Konzepte.

## Richtlinien

### Sprache & Stil

- **Schweizer Rechtschreibung** (kein ß, Strasse statt Straße)
- **Verständliche Sprache** — akademische Konzepte allgemeinverständlich erklären
- **Kritisch, aber lösungsorientiert** — Analyse soll Entscheidungen ermöglichen, nicht blockieren

### Pull Requests

1. Forke das Repository
2. Erstelle einen Feature-Branch (`git checkout -b feature/neue-perspektive`)
3. Committe deine Änderungen (`git commit -m "Add: Neue Analyseperspektive XY"`)
4. Pushe den Branch (`git push origin feature/neue-perspektive`)
5. Erstelle einen Pull Request

### Commit Messages

Verwende klare, beschreibende Commit Messages:
- `Add: Neues Beispiel für Bildungs-KI`
- `Fix: Korrektur der AI-Act-Kategorien`
- `Update: Aktualisierung der Bias-Taxonomie`
- `Docs: Verbesserung der README`

## Code of Conduct

Wir erwarten von allen Beitragenden:
- Respektvoller Umgang miteinander
- Konstruktive Kritik
- Offenheit für verschiedene Perspektiven
- Berücksichtigung des öffentlichen Kontexts dieses Projekts

## Fragen?

Erstelle ein [Issue](../../issues) oder nutze die [Discussions](../../discussions).
